# 처음 만나는 MCP: AI를 도구와 데이터에 연결하는 법

MCP(Model Context Protocol)를 처음 접하는 사람을 위한 비개발자용 실전 입문서입니다. AI가 문장을 만드는 데서 끝나지 않고 문서·검색·업무 시스템을 안전하게 사용할 수 있도록, 연결 구조와 권한·승인·감사 방법을 설명합니다.

## 이 책에서 다루는 것

- MCP가 왜 필요한지와 기존 플러그인·API 연결과 무엇이 다른지
- Host·Client·Server·Tool·Resource·Prompt를 쉬운 비유로 이해하기
- Claude Desktop·ChatGPT·IDE 등 MCP 클라이언트에 서버 연결하기
- 읽기 도구와 실행 도구, 권한·승인·비밀키를 구분하기
- 원격 MCP와 로컬 MCP의 차이, 인증과 사용자 동의
- 프롬프트 주입·악성 서버·데이터 유출을 막는 점검표
- 장시간 작업과 Tasks, 로그·관측성·비용 관리
- MCP와 A2A를 함께 사용하는 에이전트 업무 흐름

## 기준일

본문의 최신 사양 기준일은 **2026년 10월 19일**입니다. MCP 사양은 계속 바뀌므로 각 장에 공식 문서 링크와 확인 날짜를 남깁니다.
