# 00. 이 책을 읽기 전에

## MCP를 한 문장으로 말하면

MCP(Model Context Protocol)는 AI가 외부 데이터와 도구를 일정한 방식으로 사용할 수 있게 하는 연결 규칙입니다. AI에게 “내 문서를 찾아 줘”라고 말했을 때, 어떤 자료를 어디서 읽고 어떤 행동까지 허용할지 정해 주는 공통 언어라고 생각하면 됩니다.

## 왜 지금 MCP인가

기존에는 AI 서비스마다 문서 검색·캘린더·CRM·사내 API 연결을 따로 만들었습니다. MCP는 이 연결을 공통 규격으로 묶어, 한 번 만든 서버를 여러 호스트와 클라이언트에서 재사용할 수 있게 하려는 표준입니다. 공식 사양은 2026년 7월 릴리스에서 확장성·권한·장시간 작업을 강화했습니다.

## 이 책의 약속

이 책은 “MCP 서버를 만들면 AI가 무엇이든 할 수 있다”는 식으로 설명하지 않습니다. 연결할 수 있는 것과 실행해도 되는 것은 다르고, 도구를 발견하는 것과 권한을 부여하는 것도 다릅니다. 각 장에서 다음 세 질문을 반복합니다.

| 질문 | 확인할 것 |
| --- | --- |
| 무엇을 연결하는가? | 문서·데이터·도구의 범위 |
| 누가 실행하는가? | 사용자·모델·애플리케이션의 역할 |
| 문제가 생기면 어떻게 멈추는가? | 승인·로그·취소·복구 |

## 읽는 순서

처음이라면 1~5장을 순서대로 읽은 뒤, 6장에서 실제 사용 흐름을 따라 해 보세요. 운영 담당자는 7~14장의 권한·보안·관측성 장을 먼저 읽어도 좋습니다. Jev와 하네스를 이미 읽었다면 15~17장에서 세 개념이 어떻게 연결되는지 바로 확인할 수 있습니다.
